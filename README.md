## 📋 Sobre o Projeto

Este projeto consiste em um sistema de gerenciamento de estoque e produtos desenvolvido em **C**. O software realiza a leitura, manipulação e persistência de dados em arquivos no formato CSV (`produtos.csv`), permitindo a gestão de itens da loja diretamente via terminal.

### 🚀 Funcionalidades

- **Cadastro de Produtos:** Adição de novos itens ao catálogo da loja.
- **Listagem / Consulta:** Visualização dos produtos cadastrados no sistema.
- **Atualização e Remoção:** Gerenciamento do estoque de produtos.
- **Persistência de Dados:** Integração com o arquivo `produtos.csv` para salvar e carregar os dados.

## 🛠️ Como Executar

### Pré-requisitos
- Compilador C (ex: `gcc`) instalado na máquina.

### Passo a passo

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/SEU_USUARIO/gestao_de_loja.git
   cd gestao_de_loja
   ```

2. **Compile o código:**
   ```bash
   gcc main.c -o gestao_loja
   ```

3. **Execute o programa:**
   - **Linux / macOS:**
     ```bash
     ./gestao_loja
     ```
   - **Windows:**
     ```cmd
     gestao_loja.exe
     ```
